# Privacy policy — ApiVane web app, extension and agent

ApiVane does not collect, store or sell any personal data. There is no account, no analytics and no tracking.

**Web app.** Your requests, variables and history are stored only in your own browser (IndexedDB/localStorage).
Requests go directly from your browser to the API address you enter. Nothing is sent to the ApiVane author.

**Browser extension.** The extension only acts when the ApiVane web app asks it to send a request you started.
It sends that request to the address you entered and returns the response to the app. It does not read your
browsing, does not attach your cookies, and does not store or transmit any data elsewhere. The "access to all
websites" permission is needed because you choose which API to call.

**Local agent / CLI.** Runs on your computer, listens only on 127.0.0.1, and reads/writes only the `.apivane/`
folder you point it at.
